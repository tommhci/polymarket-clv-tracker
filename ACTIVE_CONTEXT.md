# Active Context

This file is the live phase-checkpoint surface for unfinished multi-step work.
Use it when a task is long enough that chat history alone is unsafe.

- It is authoritative for the current task's stated objective, scope freeze,
  last verified step, and next action.
- It is not authoritative for git state, running processes, or staged files.
  Verify those with live commands.
- Keep it compact. If it becomes long, promote durable conclusions into
  `HANDOVER.md`, `NODE_QUEUE.md`, `NODE_PROPOSALS.md`, or `governance/*`.
